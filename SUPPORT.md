# Support

For help with GoalScout Agent:

1. Run `goalscout-agent doctor`.
2. If developing from source, run `python scripts/validate_repo.py`.
3. Read `docs/troubleshooting.md`.
4. Open a GitHub issue with your operating system, Python version, command output, provider name, and delivery mode.

Do not paste API keys, webhook URLs, tokens, private chat targets, or other secrets into public issues.
