# Security Policy

GoalScout Agent is pre-1.0. Security fixes target the `main` branch.

## Reporting a vulnerability

Open a private GitHub security advisory if available, or contact the repository owner through GitHub.

Do not include real API keys, webhook URLs, tokens, passwords, or private chat targets in public issues.

## Secret handling

GoalScout Agent expects secrets through environment variables. The repository should never contain real API keys, webhook URLs, passwords, OAuth tokens, or provider credentials.
